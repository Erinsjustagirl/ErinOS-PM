# ErinOS

A pretend operating system created by Erin in PenguinMod. The real ErinOS will happen once I've learned C enough.

## Planned Features

- Filesystem
- ErinScript (custom programming language)
- Window System

## Development

Made in PenguinMod. I would love it if someone were to contribute. If you'd like to, please do!

## How to Open

Go to https://studio.penguinmod.com and select the "load from a folder" option in Files. Then, select ErinOS PM. Tada!
